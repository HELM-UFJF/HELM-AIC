# Multi-area interchange control in the holomorphic load flow with generator and thermal limits

MATLAB code and data for the paper

> G. R. S. Lima, E. J. Oliveira, L. W. Oliveira, "Multi-area interchange control embedded in the holomorphic load flow with generator and thermal limits," submitted to *Electric Power Systems Research*, 2026.

The code solves the load flow with multi-area Area Interchange Control (AIC) by the Holomorphic Embedding Load Flow Method (HELM) and by the Newton–Raphson (NR) method, with the same control equations and the same outer loop:

- One interchange constraint and one adjustment per controlled area, embedded in the HELM recursion matrix;
- Regulation of the reference area by its own generating units;
- Reactive and active power limits of the generators, return to voltage control, and loss of controllability per area;
- Thermal limits by equation swapping: when a branch is overloaded, the interchange constraint of the area is replaced by the flow constraint of the branch, which yields the transfer limit and the binding branch in a single run;
- Evaluation of the power series by an incremental form of Wynn's epsilon algorithm.

## Requirements

- MATLAB R2018a or later (tested with R2018a and R2026b). The code also runs in GNU Octave 8.
- No toolbox is required to reproduce the results.
- [MATPOWER](https://matpower.org) is required only to regenerate the operating points (folder `geracao`).

## Repository structure

| Folder / file | Content |
| --- | --- |
| `Main_*.m` | Main scripts that reproduce the results of the paper |
| `funcoes/` | Functions (one per file) |
| `dados/` | Test systems and operating points |
| `geracao/` | Scripts that generate the operating points (require MATPOWER) |

Code comments are written in Portuguese.

## Reproducing the results

Run the main scripts from the root folder of the repository; each script adds `funcoes` and `dados` to the path.

| Script | Results in the paper |
| --- | --- |
| `Main_4Barras.m` | 4-bus system: Table 1 and Fig. 4 |
| `Main_IEEE118.m` | IEEE 118-bus system with three areas: Table 2 and Fig. 5 (writes `dados_IEEE118_Transferencia.dat` and `dados_IEEE118_LimiteTermico.dat`) |
| `Main_ACTIVSg2000.m` | ACTIVSg2000 system, loss of wind generation: Table 3 |
| `Main_Benchmark.m` | Computational performance: Table 4 and Fig. 6 |
| `Main_Liu.m` | Comparison with Luo and Liu (2023): Supplementary Material, Sections S1 to S3 |

Computing times depend on the MATLAB version and on the computer.

## Test systems and operating points

| File | Description | Source |
| --- | --- | --- |
| `case4gs.m` | 4-bus system of Grainger and Stevenson | MATPOWER |
| `case118.m` | IEEE 118-bus system | MATPOWER |
| `pglib_opf_case118_ieee.m` | IEEE 118-bus system with branch ratings | PGLib-OPF v23.07 |
| `case118_base.m` | Operating point of the IEEE 118-bus study (AC OPF with 10% generation reserve and 10% thermal margin) | Generated by `geracao/Gera_Base118.m` |
| `case_ACTIVSg2000.m` | Synthetic 2000-bus Texas system | MATPOWER / Texas A&M University |
| `case_ACTIVSg2000_h5368.m`, `case_ACTIVSg2000_h8504.m` | Operating points at hours 5368 (annual peak) and 8504 (light load, high wind) of the 2016 time series | Generated by `geracao/Gera_BaseACTIVSg2000.m` |

To regenerate the ACTIVSg2000 operating points, download the 2016 load and renewable time series from the [Texas A&M Electric Grid Test Case Repository](https://electricgrids.engr.tamu.edu/activsg-time-series-data/), read them with `geracao/Le_Series_ACTIVSg2000.m` to create `Series_ACTIVSg2000.mat`, and run `geracao/Gera_BaseACTIVSg2000.m` with MATPOWER on the path. The construction of the operating points is described in Section S4 of the Supplementary Material.
